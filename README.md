# Child Attention & Engagement Analytics

Data analytics training project (NTI summer training). A proposed consulting scenario: a firm specialized in Child Learning & Engagement works with ~30 partner organizations (schools, nurseries, sports clubs, kids areas, STEM/art centers) collecting child engagement data across five dimensions — Attention & Engagement, Lifestyle, Learning Preferences, Environment, and Activity/Content Characteristics — to build a Child Engagement Design Framework.

## Project flow

1. **Project Initiation** — scenario, ERD, schema mapping
2. **Data Environment** — convert the schema into a MySQL database, load messy/dirty data into it
3. **Iterative Data Cleaning** — partial clean with SQL, partial clean with Excel/Power Query, final clean (100%) with Python
4. **Transformation** — re-import the fully cleaned file into SQL, summarize with joins/aggregations/subqueries
5. **Analytical Modeling** — Excel Power Pivot data model, DAX measures, pivot tables and KPIs
6. **Data Visualization** — summarize insights with Python, simple Power BI dashboard
7. **Final Documentation** — every step documented
